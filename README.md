# Team apm

**AviUtl Package Manager** (apm) installs and updates AviUtl plugins and scripts, so you do not have to unpack archives into the right folders by hand.

AviUtl のプラグイン・スクリプトを一括で導入・更新するツールです。

## [→ ダウンロード / Download](https://team-apm.github.io/apm/)

## Sites here

| | |
| --- | --- |
| [apm](https://team-apm.github.io/apm/) | Download and documentation ・ ダウンロードと説明 |
| [apm-web](https://team-apm.github.io/apm-web/) | Browser tool for writing package data ・ パッケージデータを作るツール |

The package catalogue apm reads is not a site — it is published from [apm-data](https://github.com/team-apm/apm-data) and served over jsDelivr.

## Source

Everything is on GitHub at [github.com/team-apm](https://github.com/team-apm). The organization profile says which repository holds what, and where to send a request or a bug report — plugin and script requests go to [apm-data](https://github.com/team-apm/apm-data/issues), not to apm.
